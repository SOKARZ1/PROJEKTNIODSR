##Projekt sterowania manipulatorem 6-ścio osiowym w przegubie numer 1.

Niniejszy projekt przedstawia symulację sterowania przegubem robota typu (Wstawić nazwę) z wykorzystaniem środowiska (Wstawić nazwę)
Aplikacja przeznaczona jest dla osób studiujących, jej głównym zadaniem jest wizualizacja procesu ruchu robota UR5.
